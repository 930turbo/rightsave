Save your first file

Open a webpage and right-click the image you want. Choose a filename and folder in Save As. If direct saving is off, use the RightSave submenu instead.

Shift + right-click opens the usual browser menu. Alt + right-click gives the website control.

Save several files in one ZIP

Open the media library from the toolbar. Load previews, open Filters & collection tools and select your files. Save selected as ZIP gives you one file and one Save As dialog.

Up to 100 files, 40 MB per file and 150 MB total. Source records leave room for 98 media files. If a host blocks ZIP requests, save its files individually.

Find a video on a social site

Open the post itself and play the video before scanning. Scroll through carousels, then rescan. Instagram, Facebook, X, Reddit, Threads and LinkedIn can expose different files after playback.

Direct MP4, WebM and Ogg files work when exposed by the page. HLS/DASH segments and protected streams cannot be combined. A Video only label means audio is separate. Site changes can affect detection.

Resize or change an image format

Load an image preview and click it. Open Convert a still image, choose PNG, JPEG or WebP, then save a converted copy. The original stays available.

Conversion runs on this device. JPEG uses a white background. Animation becomes one frame and metadata is removed. Source limit: 16 megapixels and 40 MB.

Remember your filters and filenames

Under Saved workflows, name the current setup and save it. Apply it next time to restore filters, preview size and naming rules. Export a workflow pack to move it to another browser.

Use {name}, {ext}, {index}, {site} and {date} in a filename template. For example: {site}/{name}-{index}.{ext}. Up to 20 workflows are stored locally.

Nothing appears, or a save fails

  1. Refresh the source webpage after installing RightSave.
  2. Open the post rather than its feed preview. Scroll or play it, then rescan.
  3. Keep the source tab open and stay signed into the site if it requires it.
  4. Try Save original or Open original. A blocked preview does not always prevent saving.

Firefox’s .part file is temporary. Wait for Downloads to finish. Expired links need a fresh scan. Browser settings pages and add-on store pages restrict extensions.

Firefox containers work with individual saves. ZIP and conversion cannot use a container session; the app explains this when you try.
