Three ways to save

One file

Right-click an image or supported video. Save As lets you choose where it goes.

A whole selection

Open the media library, select what you want and save it in one ZIP.

A different format

Open a larger image preview to resize it or save a PNG, JPEG or WebP copy.

Put it within reach

Open your browser’s Extensions menu and pin RightSave to the toolbar. Refresh any pages that were already open when you installed it.

Alt + Shift + S opens the media library. Hold Shift while right-clicking for the normal browser menu, or Alt for the website’s controls.
