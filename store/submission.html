Chrome Web Store

  1. Create the publisher account in the Developer Dashboard. The owner must complete registration, any identity checks and the one-time registration payment.
  2. Upload RightSave-5.2.0-chrome.zip as a new item. Use listing.txt for the description and review-notes.txt for permission explanations.
  3. Upload the 128-pixel icon and the gallery, collections and help screenshots (1280 × 800) from assets/. The promo tile and marquee are also included. Select the appropriate photo/productivity category.
  4. Declare the actual package’s privacy practices: media is processed locally and fetched from original hosts; the Free build has no developer data collection or remote executable code. Explain all-site access as necessary for finding media on arbitrary user-selected webpages.
  5. Enter the owner’s real support and publisher details. Complete any trader or distribution declarations directly. Submit for review when the dashboard’s required fields are complete. A successful upload is not approval.

Make your Firefox developer account

  1. Open Mozilla Add-ons Developer Hub in Firefox. Choose Register if you have no Mozilla Account, or Log in if you already have one.
  2. Use your own email address, complete Mozilla’s email verification and account security steps, then sign into Add-ons with that account.
  3. Complete your publisher profile and accept the developer agreement yourself. Use accurate publisher and support details.

Publish on Firefox Add-ons

  1. Create or sign into the Mozilla Add-ons Developer Hub. The owner must accept Mozilla’s distribution terms and complete any account requirements.
  2. Choose an add-on distributed on this site, then upload RightSave-5.2.0-firefox.zip. Keep the existing add-on ID from the manifest. Choose the public/listed route for a store listing.
  3. Use listing.txt for the descriptive name, summary, description, tags and screenshot captions. Enter the privacy URL, reviewer notes and your real publisher/support details. Source is unminified; the build copies local files and applies browser-specific manifest changes.
  4. Submit for validation, signing and review. Only a signed XPI confirms a permanent-installable Firefox package; only the published AMO listing confirms store availability.

Help people find it

Use the prepared descriptive title and natural phrases such as save images, video downloader, right-click and ZIP collections where they explain actual features. Put the gallery screenshot first, followed by collection saving and help. Use accurate categories and the supplied privacy and support links. Avoid keyword repetition, guaranteed rankings, platform-affiliation claims or claims that all videos work. Publish a store link on the project homepage only after Mozilla provides the real listing URL.
