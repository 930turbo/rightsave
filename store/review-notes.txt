RightSave 5.2.0 — reviewer notes

Single purpose: discover and save webpage media explicitly chosen by the user.
All features are free. No account, billing, activation or feature-gating modules
are included. No remote executable code, eval, developer backend or telemetry.
The ZIP contains readable, formatted source without a bundler or minifier.

All-site access discovers clicked media and scans user-selected pages/frames.
Menus adds the native submenu. Downloads opens Save As. Scripting scans frames.
Storage keeps preferences, user-saved workflows and temporary media lists.
Firefox cookies permission only passes cookieStoreId to downloads; cookie
values are never read. Optional webRequest starts off and observes video
response URLs/content types after the user grants permission in Settings.

The MAIN-world bridge has no extension privileges. It reads bounded selected
same-platform responses already requested by the page, without extra API
requests. Isolated code retains validated media fields, not raw responses.
Opt-out and site exceptions clear caches. Request observations skip excluded
sites and clear on navigation, tab closure and permission removal.

Koofr shared-link support observes only /api/v2/public/links/{current-share-id}
and its /bundle response on https://app.koofr.net/links/*. It reads the file,
type, name and contentType fields and preserves only the already-used password
parameter in the download URL. No extra API calls, cookie reads or account
enumeration. Thumbnail URLs are matched to the same shared file path. Firefox
download Referer uses the share path, without query strings or fragments.
All saved basenames, ZIP entries and exports use crypto.getRandomValues (128 bits).
Original labels stay in the gallery. Native Save As is always requested.

Previews and saves contact original hosts. No user data is sent to the developer.
No external credentials are needed to test the core features. The installed
quick start and How to use it pages include an offline practice image and four-second video save. Video previews load only after an explicit Play click and stop when the viewer closes or changes media. The
public demo at https://930turbo.github.io/rightsave/demo/ has three sample images.
Open the library, load previews, select files and save a ZIP to verify.

The release includes natural-language limitations: direct video files only,
no DRM bypass or HLS/DASH merging, and video-only labels for separate audio.
Test fixtures cover representative social payloads; no universal compatibility
claim is made. The developer does not control third-party platform changes.

Build: Node.js 22+, npm ci --ignore-scripts, npm run build.
The build copies extension/ and changes the browser-specific manifest only.
Validation: npm test; npm run lint:firefox; npm run preflight.
Read docs/privacy.html, docs/security.html and docs/verification.json.
