RightSaveDownloads

Website compatibility

Adapters improve media discovery on Instagram, Facebook, X/Twitter, Reddit, Threads and LinkedIn. They are not a guarantee for every post.

Site Sources Limits
Instagram / Threads Carousel images, progressive video versions, embedded and loaded page data Open the post and play video first. Login and signed-link expiry apply.
Facebook SD/HD native and progressive video fields in loaded GraphQL data DASH-only and protected playback cannot be merged.
X / Twitter MP4 variants, post/poster matching, original-size image candidates HLS-only players remain limited.
Reddit Gallery metadata, full-size candidates and fallback videos Separate-audio tracks are labeled Video only. No audio merging.
LinkedIn Progressive streams, image artifacts and loaded Voyager data Signed URLs expire. Protected/stream-only players remain limited.

Use it

Refresh pages after installing. Open the post or carousel, play video, then right-click or Rescan. Related media is matched to its poster, URL or an unambiguous post link; another cached post is not silently substituted.

Verification

Automated tests cover representative synthetic data for all six platforms, plus real browser execution worlds and saved bytes using local fixtures. They do not certify logged-in live feeds. Layouts, payloads, login rules and link lifetimes change.

ZIP export

ZIP export supports up to 100 files, 40 MB per file and 150 MB total. It fetches media locally with the browser session; some authenticated or hotlink-protected sources can reject it. Firefox container sessions should use individual Save As. Protected playback and segmented streams are not assembled.
