Release review

RightSave 5.2.0. Reviewed October 23, 2026. This documents the checks performed for this release; it is not a guarantee against every defect or future website change.

Package boundaries

The browser ZIPs contain only the extension directory. Build tools, fixtures, test profiles, secrets, billing modules and commercial configuration are excluded. All executable scripts are local and readable. The extension uses a restrictive script policy, forbids embedded objects and has no externally connectable message interface.

Data handling

No developer endpoint receives scans, downloads, diagnostics or telemetry. Explicit media requests go to their original hosts. Credentials embedded in URLs are rejected. Remote pages cannot use saving or ZIP preparation to read local files. Privileged background actions require a sender from this extension. Source exports use an allowlist and strip URL credentials, query strings and fragments. Clipboard writes require an explicit click.

Untrusted content

Social parsers bound input size, depth, node count and output. They never evaluate page text. Inline SVG export removes active content and external references. Saved basenames use 128 bits of browser cryptographic randomness. ZIP paths reject traversal; CSV records neutralize formula prefixes. Workflow imports validate every entry before writing. ZIP and conversion enforce memory limits.

Verification

Automated checks exercise real Firefox and Chromium downloads, native Save As requests, cancellation, byte-for-byte source matching, ZIP extraction, conversion, workflows, guides, keyboard controls, responsive layouts and optional-video cache cleanup. The verification report records results and source hashes. Firefox validation and development dependency audit are run before packaging.

Practical limits

Representative platform fixtures cover Instagram, Facebook, X, Reddit, Threads, LinkedIn and Koofr shared links. These do not certify every live share or logged-in feed. Stream merging and protected playback are unsupported. Existing access on the source site is still required. Files and exported records remain the user’s responsibility after saving. Mozilla signing and review are separate from local validation.
