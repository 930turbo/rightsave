RightSave

Privacy

Updated October 21, 2026. RightSave saves media locally. There is no analytics or advertising SDK, and no developer-operated media or billing server. Downloads and requested previews contact their original hosts.

Page processing

Enhanced detection is on by default. On supported social sites it reads media fields from selected API/GraphQL responses the page already requested. Response text is processed transiently, up to 2 MiB per response and two concurrent fetch readers. Only extracted media URLs, short labels, dimensions, posters and post links enter a bounded page cache. It does not send these to the developer or payment provider, read request bodies or make extra platform API calls.

The cache clears on detected route changes, feature opt-out, host exclusion and document closure. Explicit scans also read DOM media, embedded JSON, Open Graph and JSON-LD. You can disable enhanced detection in Settings.

Stored on your device

Preferences, license tokens or purchase keys and instance IDs, last license-check times, and explicitly saved workflows use browser local storage. Workflows can contain search text, filters and naming templates. Delete them in the library. Temporary libraries, page URLs, observed video URLs and download bookkeeping use session storage. The browser keeps its own download history.

ZIP contents stay in memory until download. Studio workflow packs and source records are files you explicitly export. Records include filenames, dimensions, byte counts and source links with query strings and fragments removed. URL paths can still identify a private post; keep exported records private. Imported packs are validated and stored locally.

Paid licenses and checkout

The public Free build has no configured payment provider and makes no billing requests. In an explicitly configured paid build, clicking a purchase link opens Lemon Squeezy hosted checkout. The provider processes payment details under its own privacy policy. RightSave does not receive card details.

Activating a paid license sends the key and a random browser-instance label to api.lemonsqueezy.com. Later validation and deactivation send the key and provider instance ID. Your IP address is visible to the provider as with any direct HTTPS request. Checks happen when paid features are used, usually after 24 hours or when a new background session starts. An explicit Check license button forces a check.

Provider replies may include purchase and customer information. RightSave retains only the license key, instance ID, configured product identity, tier, expiry and check time. It does not retain customer names or emails. Browsing history, page scans, saved files and media URLs are not sent in license requests. There is up to a seven-day offline grace period after a successful check.

Deactivate this browser releases its provider activation and removes the purchase key locally. A failed request keeps the key and instance so you can retry. Losing or uninstalling a profile does not automatically release its provider activation; contact the merchant for recovery. Separate signed offline licenses are verified locally and make no billing requests.

Permissions

Website access discovers chosen media and restores right-click. Menus adds the native submenu; downloads opens Save As; scripting scans frames; storage saves preferences and temporary lists. Firefox cookies permission passes the correct container ID to its download manager; RightSave never reads cookie values. Optional webRequest observes video response URLs/content types and starts disabled. A merchant-configured Firefox build declares authentication-information transmission for license checking; the default Free build declares no data collection.

Questions

Use GitHub Issues for general questions. Never publish purchase keys, cookies, signed media links or private files in a report. Ask for private purchase recovery through the merchant contact on your receipt.
