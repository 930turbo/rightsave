RightSaveDownloads

Privacy

RightSave runs locally. No analytics, advertising SDK, account service or developer-operated backend is active. Downloads and requested previews contact their original media hosts.

Page processing

Enhanced detection is on by default. On supported social sites it reads media fields from selected API/GraphQL responses the page already requested. Response text is processed transiently, up to 2 MiB per response and two concurrent fetch readers. Only extracted media URLs, short labels, dimensions, posters and post links enter the bounded page cache. No request bodies, extra platform API calls or developer uploads.

The cache clears on detected route changes, feature opt-out, host exclusion and document closure. Explicit scans also read DOM media, embedded JSON, Open Graph and JSON-LD. You can disable enhanced detection in Settings.

Stored locally

Preferences, optional signed licenses and explicitly saved Pro workflows stay in browser local storage. Workflows can contain search text, filters and naming templates; remove them in the library. Media libraries, optional observed video URLs and download bookkeeping use session storage. The browser keeps its own download history. Pro ZIP contents stay in memory until download and are not uploaded.

Permissions

Website access discovers chosen media and restores right-click. Menus adds the native submenu; downloads opens Save As; scripting scans frames; storage saves preferences and session lists. Firefox cookies permission passes the correct container ID to its download manager; RightSave never reads cookie values. Optional webRequest observes video response URLs/content types only and starts off disabled.

Commercial links

No checkout or contribution destination is active. Future external payment links open their provider directly. License signatures are checked locally. Any future server or billing integration must update this notice before release.
